PASO 0

Prepara tu agente con gentle-ai

gentle-ai configura el agente que ya usas (Claude Code, Codex, Cursor, OpenCode, Gemini CLI y más) con memoria persistente (Engram), skills, MCP y un flujo de trabajo ordenado.

Sin IA
# macOS
brew install gentleman-programming/tap/gentle-ai
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Gentleman-Programming/gentle-ai/main/scripts/install.sh | bash
# Windows (requiere Go 1.25.10+)
go install github.com/gentleman-programming/gentle-ai/v4/cmd/gentle-ai@v4.1.1

gentle-ai          # elige agentes, componentes y persona
gentle-ai doctor   # verifica la instalación
Con IA
Instala gentle-ai en mi sistema siguiendo el README oficial de https://github.com/Gentleman-Programming/gentle-ai. Antes de ejecutar cada comando, muéstramelo y explícame qué hace. Al final ejecuta `gentle-ai doctor` y resúmeme qué quedó configurado.

El asistente gentle-ai es interactivo: ejecútalo tú en tu terminal para elegir tu agente.

PASO 1

Stellar CLI: de cero a testnet

Sin IA
# Instalar
winget install --id Stellar.StellarCLI      # Windows
brew install stellar-cli                     # macOS / Linux
rustup target add wasm32v1-none              # Rust para contratos

# Primer contrato
stellar keys generate alice --network testnet --fund
stellar contract init soroban-hello-world
cd soroban-hello-world
stellar contract build
stellar contract deploy --wasm target/wasm32v1-none/release/hello_world.wasm --source-account alice --network testnet --alias hello_world
stellar contract invoke --id hello_world --source-account alice --network testnet -- hello --to RPC
Con IA
Instala la Stellar CLI y el target de Rust wasm32v1-none en mi sistema. Luego crea una cuenta de testnet llamada alice con fondos, inicia el proyecto soroban-hello-world, compílalo, despliégalo en testnet con el alias hello_world e invoca la función hello con el argumento RPC. Muéstrame cada comando antes de ejecutarlo y explícame el resultado.

PASO 2

Stellar Skills: contexto antes del código

Una skill le da al agente el contexto correcto de Stellar antes de escribir código.

  • Smart Contracts
  • Frontend & Wallets
  • Assets & SAC
  • RPC & Horizon
  • Agent Payments (x402 + MPP)
  • ZK Proofs
  • SEPs & CAPs
  • Cross-Chain
Sin IA
# Claude Code (escríbelo dentro del agente)
/plugin marketplace add stellar/stellar-dev-skill
/plugin install stellar-dev@stellar-dev

# Codex, Cursor, VS Code y otros
npx skills add https://github.com/stellar/stellar-dev-skill
Con IA
Instala las Stellar Skills oficiales de https://github.com/stellar/stellar-dev-skill en este agente usando el método que recomienda skills.stellar.org. Cuando termines, lista las skills que quedaron disponibles y dime para qué sirve cada una.

Las skills de la comunidad no las revisa la SDF: léelas antes de instalarlas. Más en skills.stellar.org.

PASO 3

MCP: conecta tu agente a Stellar

Stellar Docs MCP · documentación oficial, sin login.

Raven · docs y datos vivos del ecosistema, herramientas search y execute, login con OAuth.

Sin IA
# Claude Code
claude mcp add --transport http --scope user stellar-docs https://developers.stellar.org/mcp
claude mcp add --transport http stellar-raven https://raven.stellar.org/mcp
# luego, dentro del agente: /mcp → Authenticate (Raven)

# Codex
codex mcp add stellar-docs --url https://developers.stellar.org/mcp
codex mcp add stellar-raven --url https://raven.stellar.org/mcp
codex mcp login stellar-raven
Con IA
Agrega a la configuración de mi agente dos servidores MCP de Stellar: Stellar Docs (https://developers.stellar.org/mcp, sin login) a nivel de usuario, y Raven (https://raven.stellar.org/mcp). Verifica que ambos aparezcan conectados y dime cómo completo el login de Raven.

Plan B: ¿tu herramienta no soporta MCP? Pega https://developers.stellar.org/llms.txt en el chat.

MANOS A LA OBRA

De la idea a testnet

Sin IA
stellar contract init propinas
cd propinas
# escribe el contrato en Rust en contracts/hello-world/src/lib.rs
cargo test
stellar contract build
stellar contract deploy --wasm target/wasm32v1-none/release/hello_world.wasm --source-account alice --network testnet --alias propinas
Con IA
Usa las Stellar Skills y el MCP de Stellar Docs. Crea un contrato Soroban de propinas: cualquier cuenta puede enviar propinas en un token a un creador y el creador puede retirarlas. Escribe tests, ejecútalos, compila el contrato y despliégalo en testnet con la CLI usando la cuenta alice y el alias propinas. Detente y muéstrame el código antes de desplegar.
  1. 01SkillPatrones correctos de Soroban
  2. 02MCPDocumentación vigente
  3. 03CLITests y compilación
  4. 04TestnetDespliegue y contract ID
