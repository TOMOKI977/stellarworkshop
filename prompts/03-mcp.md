# Paso 3 · MCP: conecta tu agente a Stellar (Con IA)

Pega este prompt en tu agente:

```text
Agrega a la configuración de mi agente dos servidores MCP de Stellar: Stellar Docs (https://developers.stellar.org/mcp, sin login) a nivel de usuario, y Raven (https://raven.stellar.org/mcp). Verifica que ambos aparezcan conectados y dime cómo completo el login de Raven.
```

## Qué esperar

- `stellar-docs` conectado sin login.
- `stellar-raven` agregado y pendiente de autenticación OAuth.
- Las instrucciones para completar el login de Raven.
