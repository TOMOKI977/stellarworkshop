# Manos a la obra · De la idea a testnet (Con IA)

Pega este prompt en tu agente:

```text
Usa las Stellar Skills y el MCP de Stellar Docs. Crea un contrato Soroban de propinas: cualquier cuenta puede enviar propinas en un token a un creador y el creador puede retirarlas. Escribe tests, ejecútalos, compila el contrato y despliégalo en testnet con la CLI usando la cuenta alice y el alias propinas. Detente y muéstrame el código antes de desplegar.
```

## Qué esperar

- Un contrato de propinas escrito con patrones correctos de Soroban.
- Tests que pasan con `cargo test`.
- Una pausa para que revises el código antes del despliegue.
- El contract ID en testnet con el alias `propinas`.
